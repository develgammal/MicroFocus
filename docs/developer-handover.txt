MicroFocus: Developer Handover & Architecture Documentation (Vue 3 Edition)
============================================================================

1. Project Overview
-------------------
MicroFocus is a mindful productivity tracker that measures "Focus Quality" rather
than just duration. Originally built as a monolithic single-file HTML proof of concept,
it has been rebuilt as a full Vue 3 application with TypeScript, Pinia state management,
vue-i18n internationalisation, Tailwind CSS design system, and comprehensive testing.

Core Philosophy: "Quality over Quantity."

Architecture: Vue 3 SPA (Composition API, <script setup>)
Build Tool: Vite
Language: TypeScript (strict, zero `any` types)
State: Pinia stores with localStorage persistence
Styling: Tailwind CSS v4 with CSS custom properties design system
i18n: vue-i18n with extracted locale files
Testing: Vitest (unit) + Playwright (E2E)

2. Migration Notes
------------------
- The old storage key `focusFlowData_v6` is auto-migrated on first load via
  `src/utils/storage.util.ts` → `migrateFromLegacy()`.
- New storage key: `microfocus_v1`.
- The original proof-of-concept is preserved as `proof-of-concept.html`.

3. Key Design Decisions
-----------------------
a) Web Worker Timer: Uses Vite's native Worker syntax (`new Worker(new URL(...))`)
   instead of inline Blob for proper TypeScript bundling and source maps.
   
b) Audio Synthesis: All 7 soundscapes remain procedurally generated via Web Audio API.
   Encapsulated in `src/composables/useAudioSynth.ts`.

c) Alarm Loop: Recursive timeout pattern for sound/TTS interleaving preserved from
   the original. Encapsulated in `src/composables/useAlarmLoop.ts`.

d) Design System: CSS custom properties defined in `src/assets/styles/main.css`
   consumed by Tailwind's `@theme` directive. Dark mode via `.dark` class on <html>.

e) No hardcoded strings: All user-facing text goes through vue-i18n translation keys.
   Locale files in `src/i18n/locales/`.
